## Quick Start

### Prerequisites
Python 3.10+

### Installation
```bash
git clone https://github.com/d3mio/auto-log-sentinel-analyzer
cd auto-log-sentinel-analyzer
pip install -r requirements.txt
```

### Usage
```bash
python log_sentinel.py --file app.log --threshold 5
```
